# Homepage Project

This repository contains the HTML and CSS implementation of a homepage layout based on a provided Figma design. The goal is to reproduce the structure and appearance as accurately as possible.

---

## 📄 Project Description

This project is a webpage built using HTML and CSS only, following a wireframe and visual reference provided. The layout includes:

* A header with site logo and navigation links
* A hero/first section with main title, subtitle text, button and feature images
* Additional structured sections (products, cards, testimonials, footer, etc.)

The objective is to visually match the Figma design while maintaining clean, well‑organized code.


---

## 🔧 Technologies Used

HTML5
CSS

No frameworks, JavaScript, or external libraries were required unless later added.
